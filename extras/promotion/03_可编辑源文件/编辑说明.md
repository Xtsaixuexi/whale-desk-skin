# 编辑与再次导出

直接发布不需要运行脚本，使用上一级 `01_发布图片` 中的八张 PNG 即可。

- `index.html`：八页的实际文字、图片引用与排版结构。修改标题或正文时编辑这里。
- `style.css`：配色、字体、位置、字号和固定的 1440 × 1920 画幅。
- `project.json`：文案、图序和素材来源清单，便于继续整理；不会自动双向同步 HTML。
- `assets`：随包原始素材、字体和许可，保持目录一起移动。
- `render-validation.json`：首次导出的尺寸和文字越界检查记录，不会随你手动改稿自动更新。

修改后在浏览器打开 `index.html` 查看。字体和图片直接从本地加载，不需要登录网站。图片不做重绘，整页排版由 HTML/CSS 生成。

## 再次输出 PNG

需要 Node.js 与 Playwright。已有可用的 Playwright 环境时，用 `PLAYWRIGHT_MODULE_PATH` 指向包含 Playwright 的 `node_modules`；如果使用自备 Chrome/Chromium，用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指向其可执行文件。也可在本目录自行安装 Playwright 并准备其 Chromium。

在本目录执行：

```sh
node export.mjs
```

会覆盖上一级的八张发布图和图片总览。请先保存想保留的旧版。只重做总览可执行 `node export.mjs --contact-only`。

脚本只读取本地资源并导出文件，不连接 DSH，不向小红书上传，也不发送任何内容。再次导出后，请逐页确认文字不被遮挡、图序正确和引用说明仍准确。
