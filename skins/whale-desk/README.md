# 鲸伴 · 水彩小书桌 / Whale Desk

DSH Skin v2 · 1.1.1 · 基于 Alphazerolan 的 DIY Journal 1.14.1。

奶油暖木、水彩鲸鱼娘与紫粉柔字。将本目录完整复制到 DSH 数据目录下 `skins/whale-desk`，在设置 → 皮肤中选择 Whale Desk。目录名须与 manifest ID 一致；皮肤本身不需要构建或 Python。

包含首页、侧栏、消息、菜单、设置和任务等区域的样式。桌宠由 DSH 独立管理，本包不含桌宠动作。当前默认不注册 JavaScript 钩子，保留原生状态的 CSS 回退。

本包预览图为实际背景素材，不是实机截图。1.1.0 部分页面已观察；1.1.1 完整实机回归待完成。

个人修改前备份本目录；默认图片、字体和配套素材均在 `assets` 中。完整仓库另提供离线配置器、功能对照及测试记录。维护者编辑 `DESK-OVERRIDES.css` 后需同步到实际加载的 `patches.css`。
