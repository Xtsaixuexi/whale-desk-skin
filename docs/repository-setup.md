## 首次运行

皮肤安装按原 README；新增内容分别见 `extras/README.md` 与 `docs/repository-setup.md`。

## 内容范围

保存当前可编辑源码、运行入口、现有测试、文档和必要的示例素材。原电脑上的工作目录与运行状态保留。

本仓库不包含真实 API 密钥、登录状态、个人数据库、任务历史、日志、虚拟环境、node_modules、构建缓存和历史备份。配置示例需要在新机器上按自己的环境填写；操作系统凭据库需要重新配置。根目录重复交付 ZIP 不纳入源码仓库；程序直接引用的示例素材包保留。

上传准备只验证记录中列明的检查。既有文档里的历史测试记录不代表在另一台电脑上重新验收；不自动调用付费模型、不安装计划任务、不部署服务。

## 后续更新

在这个 Git 仓库目录完成改动后，用 `git status` 核对文件，再提交与推送。修改原电脑的旧工作目录不会自动同步到这里。
