## 独立能力与本次补充

| 能力 | 上游情况 | 本项目情况 |
| --- | --- | --- |
| 桌宠动作包 | 皮肤仓库不包含；独立安装 | 同样不打包，本机已有宠物可继续使用 |
| 设置页宠物插画 | 包含 | 包含，和桌宠动画是两件事 |
| 可视化设置入口 | [另一个插件](https://github.com/Alphazerolan/diy-journal-settings)，面向 diy-journal | 新增离线配置器，无 DSH 内嵌入口 |
| 逐区选图／隐藏 | 独立插件提供 | 新增 14 个区域的单图替换和隐藏 |
| 色彩、字号、输入框宽度、顶栏题字 | 部分由样式或插件控制 | 新增统一配置与导出应用工具 |
| 双照片、层叠、胶带、旋转、题字拼贴 | 独立插件提供 | 未实现；不将其列作已拥有 |
| 运行状态投影钩子 | 可选，需要宿主信任 | 不注册；保留 CSS 回退，不绕过宿主审核 |
| README、安装、贡献、更新与许可 | 包含 | 本次补齐独立版本 |
| 组件画廊 | 静态示例和实机截图 | 本次补齐素材画廊与范围说明；未复制上游截图冒充本皮肤 |
| 自动发布检查和问题模板 | 包含 | 本次补齐独立检查、配置测试、CI 与模板 |

因此，主皮肤的组件基础没有少一整类；但不能称为原作者“皮肤＋独立插件＋动态增强”的完全等价复刻。未完成的插件交互和实机回归保留在公开说明中。
