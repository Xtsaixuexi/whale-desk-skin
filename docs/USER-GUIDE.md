## 这套皮肤包含什么

鲸伴是一套给 DeepSeek Harness 使用的外观资源。主视觉是奶油暖木、水彩鲸鱼娘、鲸鱼玩偶与紫粉文字；原有侧栏、会话、输入区和工作台位置继续由 DSH 管理。

随包包含主题 CSS、插画、字体、离线配置器、配置应用工具、中文与英文说明，以及 100 张展示图片。默认输入区最大宽度为 760 px，正文界面采用霞鹜文楷，艺术标题采用龙藏体，代码保留等宽字体。

安装皮肤不会提供模型额度、登录账户或安装功能插件。使用预览图中的任务看板、自动化等入口，仍需 DSH 本身或相应插件提供功能。

## 第一次使用

1. 打开 [仓库首页](https://github.com/Xtsaixuexi/whale-desk-skin)，下载完整仓库并解压。下载后的网页文件要在本机打开，GitHub 页面主要用于阅读源码与说明。
2. 找到解压目录里的 `skins/whale-desk`，确认其中直接有 `skin.json`、`patches.css` 和 `assets`。
3. 按 [安装说明](../INSTALL.md) 将这个文件夹复制到 DSH 的皮肤目录。
4. 打开 DSH，进入“设置 → 皮肤”，选择“鲸伴 · 水彩小书桌 / Whale Desk”。
5. 打开一个新会话，确认背景、品牌字标与输入托盘出现。菜单名称或位置可能随宿主版本变化。

**完成标志：** DSH 的皮肤列表能识别鲸伴，并且新会话页面显示书桌背景。只在文件夹中看到图片，或只打开离线画廊，不算已应用到 DSH。

## 怎样查看浅色与深色

皮肤包含两套配色，实际显示哪套由宿主主题状态决定。请使用 DSH 提供的主题设置；离线配置器中的“日光 · 浅色 / 晚灯 · 深色”按钮只切换正在编辑和预览的配色，不会切换 DSH。

当前深色静态示例已发现部分账户卡、问答面板和触发通知的文字对比度不足，任务卡与插件卡也有待打磨。具体记录见 [测试状态](TESTING.md)。文档中保留渲染结果，不将其写成全面兼容。现在若想优先获得更稳定的阅读效果，可以先使用浅色，并在升级皮肤前保存改稿。

## 第一次 DIY：从一处小改动开始

下面以“把输入区收窄，换一句顶栏题字”为例：

1. 在已解压仓库内打开 `tools/editor.html`，保持它与同目录的 CSS、JS 文件以及上一级的 `skins` 目录一起存在。
2. 将“输入框最大宽度”设为 `680 px`，将“顶栏题字”改成“先写一个小想法”。
3. 在右侧看颜色和素材示意。这个预览不是实时 DSH，宽度也不是实际窗口的等比例截图。
4. 点击“导出配置”，保存 `whale-desk.config.json`。若关闭网页前没有导出，改动不会自动保存。
5. 使用 [DIY 应用步骤](CUSTOMIZATION.md#应用到皮肤) 将 JSON 应用到仓库内的皮肤。
6. 将生成后的皮肤安装到 DSH，重新选择皮肤，必要时重启应用。

也可以从 [紧凑书写示例](examples/compact-writing.json) 开始，在配置器中导入后继续调整。示例不会包含私人图片；它使用默认配色并把其他未填写项恢复为默认值。

**记住这条路径：** 网页编辑 → 导出 JSON → 命令应用 → 安装生成的皮肤 → 在 DSH 中查看。只改网页而不执行后面的步骤，DSH 不会变化。

## 桌宠、插件与皮肤

| 看到的东西 | 由谁提供 | 皮肤能否替换 |
| --- | --- | --- |
| 首页坐在书桌边的鲸鱼娘 | 背景图片 | 可以，通过“首页背景”换整张图 |
| “宠物”设置页中的角色画 | 设置配图 | 可以，通过“宠物设置插画”换图 |
| 桌面上可移动的角色 | DSH 宠物功能及已安装宠物包 | 不能，需使用 DSH 的宠物管理功能 |
| 任务看板、插件页、自动化 | DSH 或相应插件 | 皮肤仅改变已有界面的视觉样式 |
| 原作者的 DIY Journal 设置插件 | 上游的独立插件项目 | 不作为鲸伴配置入口；本项目使用自己的离线配置器 |

本仓库没有独立桌宠动画包。装完皮肤后桌宠不变，是目前的正常行为；也不要把静态人物 PNG 当作可直接导入的动画包。鲸伴未完成桌宠拖动、动作切换与遮挡的完整实机回归。

## 日常保存与更新

建议同时保存两样东西：一份自己喜欢的配置 JSON，以及一份当前正常显示的完整 `whale-desk` 文件夹。JSON 便于把改稿带到新版，整个文件夹便于恢复旧版素材与样式。

更新时先将旧文件夹复制到 DSH 数据目录之外，再下载新版本。在新仓库重新应用保存的 JSON，确认成功后安装。`--reset` 只恢复当前皮肤版本的默认覆盖样式，不会自动退回旧版本。

每次配置应用都会在目标皮肤下生成 `.whale-desk-backups` 备份。它保存本次修改前的 `patches.css`，以及当时存在的配置 JSON；它不是整个皮肤素材目录的备份。完整更新和恢复步骤见 [INSTALL.md](../INSTALL.md)。

## 分享与再创作

个人改稿可以继续使用离线配置器制作。分享前应分别判断代码、字体与图片的使用范围：代码与文档采用 MIT，字体使用 SIL OFL，随附插画和角色素材的范围单独写在 [素材许可](../LICENSE-ARTWORK) 与 [NOTICE](../skins/whale-desk/NOTICE) 中。

本项目是基于 DIY Journal 的非官方二创，保留原作者署名。现有插画按仓库记录限个人非商业使用，角色再分发授权未独立核实。公开分享新素材时请补上你有权分享的来源与许可，不能因为代码使用 MIT 就把所有插画视为可商用。

个人配置中的图片会内嵌到 JSON 和应用后的 CSS 中；如准备发布自己的仓库，请先保存个人配置，再恢复默认并运行发布检查。详细流程见 [发布指南](RELEASING.md)。
