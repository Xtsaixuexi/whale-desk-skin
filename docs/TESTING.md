## 未完成与不能外推的范围

- 重启前的工作区自动回退未在本轮复测中重现；没有确定其根因，也没有修改宿主程序或账号权限。
  账户详情页此前报错没有单独复核；本轮短消息成功不能外推全部账户后端健康。
- 已安装皮肤的正常退出再启动通过；干净机器首次安装未测。模型菜单与 High → Low → High 等级切换已验；未逐一切换全部模型。
  更长时间流式输出、网络中断重连、重试上一轮、文件真实交付及后台任务仍未完整验收。
- 桌宠显示、点击反馈、拖动和悬浮面板可见；全部动作、Live2D 与其他宠物渲染器未完整验收；皮肤本身不提供动画引擎。
- 后续通过系统窗口菜单成功调整到 954 × 822：侧栏自动收起、手动展开、模型菜单打开及 Escape 关闭通过；代码与输入卡随宽度重排。展开侧栏后模型按钮文字截短，完整名称可在菜单读取。桌宠再次靠近发送区，移至右上方后控件露出；结束时窗口最大化。尚未实测更窄尺寸、全部窗口缩放比例和窄窗口发送。
  [954 px 原生截图](../evidence/native/narrow-chat-dark.jpg) 隐藏了账户侧栏。
- 键盘全流程、真实高对比度系统、真实移动设备、macOS/Linux 与较新 DSH 原生宿主未测。
- 使用 CSS Modules 的宿主选择器存在版本敏感性；目录校验成功不能保证未来宿主版本的全部布局。
- 插画、字体和预览的来源与使用限制见 NOTICE；角色再分发授权尚未独立核实，市场入库仍需维护者审核。

## 复现命令

```sh
node --test tests/configure.test.mjs
node scripts/check-release.mjs
node scripts/test-browser.mjs
```

浏览器脚本需要 Playwright 和可用的 Chromium。可通过 `PLAYWRIGHT_MODULE_PATH`
指定模块目录，通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定 Chrome。
转换后回归另设置 `SKIN_CENTER_MODULE` 和 `SKIN_CENTER_VERSION`：
0.4.8 指向其 `lib/index.js`；0.4.16 指向 `lib/css-safety.js`。
测试使用隔离页面和虚构数据，不连接 DSH 账户。

完整图册由 `node scripts/render-previews.mjs` 重建，图片有静态预览标注。
原生截图只在隐藏账户与会话信息后用于市场证据；不把静态示例当作原生验证。
历史验证基线仍见 [VALIDATION.json](VALIDATION.json) 和 [UPSTREAM-AUDIT.json](UPSTREAM-AUDIT.json)。
